# iFIT (intelligent File and Inventory Tracking)

The iFIT (intelligent File and Inventory Tracking) system is a flexible, technology-agnostic platform by [Idox Group](https://www.idoxgroup.com/solutions/hospital-asset-tracking-records-management/irecords/) designed for high-volume healthcare environments. It utilizes RFID, Bluetooth (BLE), GPS, and Wi-Fi to provide a real-time audit trail for patient case notes and medical assets. [1, 2, 3, 4, 5] 

## System Specifications
The iFIT platform is built to integrate with existing hospital infrastructure and national safety standards: [6] 

* Compliance: Fully compliant with GS1 standards and aligned with the Scan4Safety initiative. [6, 7] 
* Core Hardware: Uses a combination of passive RFID tags (including specialized rubber or hard tags for metal equipment), fixed sensors/antennas at entry/exit points, and handheld scanners (like the Denso BHT-M80). [5, 8, 9] 
* Software Integration: Features an open API for integration with Patient Administration Systems (PAS), Electronic Document and Records Management Systems (EDRMS), and asset management tools like E-Quip or ECRI. [1, 7, 10] 
* Deployment: Supports both on-premise and cloud-based models (ISO27001 and Cyber Essentials accredited). [11, 12] 

## Key Features & Interface

The system provides a central management hub with the following capabilities:

* Real-Time Dashboards: Web-based graphical views (GIS integration) show precise asset locations and status.
* Geofencing: Automatic alerts trigger if a tracked item (such as a case note) enters or exits a virtual boundary.
* Comprehensive Reporting: Includes 10 standard reports covering asset history, sterilisation, and utilisation status.
* User Management: Role-based access control with detailed audit trails for every file interaction. [5, 7, 10, 13, 14]

Official documentation is typically provided directly to NHS Trusts by Idox during implementation. However, high-level guides and case studies are available:

* User Guides: General administrative guides for Idox systems cover [User Administration](https://legacy.tendringdc.gov.uk/sites/default/files/documents/TED/Idox%20EDRMS%205.1%20Administrator%20Guide%20%281%29.pdf) and [Document Tracking](https://www.southdowns.gov.uk/app/uploads/2022/02/Idox-PA-for-Planning-User-Guide-3.4.pdf).
* Case Studies: Detailed implementations, such as the [East Sussex Healthcare Trust](https://www.idoxgroup.com/case-studies/east-sussex-healthcare-nhs-trust-implementing-digital-tracking-technology-to-transform-the-management-of-patient-records/) case study, outline the transition from manual logging to automated RFID tracking.
