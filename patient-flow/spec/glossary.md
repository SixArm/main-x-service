# Glossary

| Term | Meaning |
|---|---|
| **ADT** | Admission / Discharge / Transfer — the HL7 v2 message family for patient movement (A01 admit, A02 transfer, A03 discharge) |
| **Bay** | A room subdivision of a ward, typically 4–6 beds; carries sex designation |
| **Bed card** | The per-bed tile on a ward whiteboard |
| **BFF** | Backend-for-frontend — the SvelteKit server that holds the session and calls the API |
| **CCD** | Clinical Criteria for Discharge — the conditions under which the patient can leave, set at admission (SAFER "A") |
| **Cohorting** | Grouping patients confirmed with the same organism in one bay during an outbreak |
| **DTOC** | Delayed Transfer Of Care — a patient medically ready to leave who remains in an acute bed |
| **EDD** | Expected Date of Discharge, set at admission assuming ideal recovery |
| **Escalation beds/ward** | Surge capacity opened when the hospital exceeds occupancy thresholds |
| **IPC** | Infection Prevention and Control |
| **LOS** | Length Of Stay |
| **MDT** | Multi-Disciplinary Team — the cross-profession group at board rounds |
| **Outlier** | A patient placed on a ward of the wrong specialty for capacity reasons |
| **PAS** | Patient Administration System — a trust's ADT system of record |
| **Pathway (P0–P3)** | NHS discharge-to-assess pathways: P0 simple home; P1 home with support; P2 community bed; P3 24-hour-care assessment |
| **Red2Green** | Day-classification method: a green day moves the patient toward discharge; a red day does not, and records delay reasons |
| **SAFER** | The NHS patient-flow bundle: Senior review · All have EDD+CCD · Flow by 10am · Early discharge · Review long stays |
| **Side room** | Single-occupancy room, used for isolation or privacy |
| **Step-up / step-down** | Moving a virtual-ward patient into a physical bed / a physical inpatient home to a virtual ward |
| **Turnaround** | Time from bed vacated to bed available (cleaning cycle) |
| **Virtual ward** | Hospital-at-home: acute-level care and monitoring delivered in the patient's home, managed as a ward |
| **Whiteboard** | The ward's at-a-glance patient/bed board — here, a live touchscreen |
